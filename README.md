KUROBIKARI
Downtown no Gaki no Tsukai ya Arahende!! Zettai ni Tsukamatte wa Ikenai
Gasu Kurobikari Land - PC version (with a switchable English translation)
========================================================================

HOW TO START
  1. You need your own copy of the game: the decrypted .3ds file.
  2. Double-click Kurobikari.exe.
     The first time, it asks you to choose the .3ds file and remembers it.
     (Or put the .3ds file in this folder - then it is found by itself.)

  Nothing has to be installed. Windows 10 or 11.

LANGUAGE
  Press F8 at any time to switch between Japanese and English.
  The voices stay Japanese.

CONTROLS (press F1 in the game for the full list)
  Walk ................ W A S D       (hold Left Shift to walk slowly)
  A (pick up / throw) . K
  B (reset camera) .... J
  X / Y (item / map) .. I / U
  Turn the camera ..... Q / E, or hold the right mouse button and move the mouse
  Start / Select ...... Enter / Backspace
  Touch screen ........ left-click on the small (bottom) screen
  Gamepad ............. Xbox-style controllers work (plug in any time)

  F2  screen layout          F3  move the small screen
  Tab swap the two screens   F11 or Alt+Enter  fullscreen
  F5  reload settings        F8  Japanese / English

SETTINGS
  config.ini (made on the first start) holds every setting, including all
  the keys. Open it with Notepad - every line is explained. Save it, then
  press F5 in the game. Delete it to get the default settings back.

FILES THE GAME MAKES IN THIS FOLDER
  config.ini      your settings (also where your .3ds file is, if it is
                  somewhere else - delete it before sharing this folder)
  save\           your saved game
  shadercache\    speeds up loading - can be deleted any time
  kurobikari.log  a record of the last start, useful if something goes wrong
